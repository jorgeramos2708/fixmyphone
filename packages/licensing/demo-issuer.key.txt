# Que sea
# -------
# Es la mitad privada del par Ed25519 cuya mitad publica esta embebida en
# `apps/desktop/src/main/public-key.ts`, dentro del `.exe`. Quien tenga este
# archivo puede firmar cualquier licencia que la app vaya a aceptar: premium,
# diez anos, la que quiera.
#
# Por que se publica
# ------------------
# Para que quien clone el repositorio pueda probar el producto entero sin
# comprar nada ni hablar con nadie:
#
#     node packages/licensing/src/cli.ts demo --out demo.fmp
#
# Es una licencia de evaluacion honesta. Llega con su identificador registrado
# dentro del informe, de modo que un informe hecho con ella se distingue de uno
# hecho con una licencia de verdad. No es un giveaway disfrazado.
#
# Lo que NO se puede hacer con esto
# ---------------------------------
# Cobrar. La verificacion es offline y el `.exe` lleva una sola clave publica
# dentro, asi que no hay manera de distinguir "esta licencia me la emitio el
# taller" de "esta licencia me la emitio el que copio el repositorio". Quien
# tenga este archivo emite las que quiera, para siempre, y por eso mismo el
# producto de este repositorio no puede cobrar.
#
# Esto es una decision, no un descuido. Y es de las que se olvidan.
#
# Como se pasa a produccion
# -------------------------
# Cuando haya clientes de verdad, y no antes:
#
#     1. Mueve este archivo fuera del repositorio y borralo del historial.
#        `git log` lo conserva mientras este commit exista.
#     2. node packages/licensing/src/cli.ts keygen
#     3. Copia el valor que imprime a ISSUER_PUBLIC_KEY_B64URL, en
#        apps/desktop/src/main/public-key.ts
#     4. npm run dist
#     5. node tools/probar-clon-limpio.mjs   <- debe FALLAR, y por el motivo
#                                               correcto
#
# Las licencias de demostracion dejan de aceptarse en el paso 4. Eso es lo
# correcto: la demo era de prueba y la prueba se acabo.
#
# Mientras tanto, esta clave no es un secreto y no debe tratarse como si lo
# fuera. Publicarla no agrega un riesgo que no exista ya: cualquiera que
# descargue el `.exe` puede leer la clave publica de dentro con un editor de
# texto.
